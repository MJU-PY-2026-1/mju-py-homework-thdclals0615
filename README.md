# 🐍 [2026-01] 나만의 파이썬 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
축구경기 분석 및 보상 판정 시스템


## 2. 시나리오 (5~10줄)
이 프로그램은 축구경기 내용을 분석하고 특정 기준에 각 팀에 보상을 분배하는 시스템입니다.
먼저 팀의 리스트 및 팀의 명성, 경기의 중요도(ex결승, 준결승, 8강, 예선 등)를 입력 받고, 이어서 관중 숫자를 입력시킵니다. 그 후 차례로 각 팀의 중심 잡아주는 주장선수와 각 팀의 감독이 사용하고 팀의 색깔을 들어내는 핵심 전술 및 핵심 포지션을 입력하여 경기의 기초 데이터를 형성시켜줍니다. 입력된 전술과 포지션 등과 같은 데이터를 바탕으로 경기를 분석합니다. 그후 경기 결과에 해당하는 각팀의 최종적인 골 숫자, 경기에서 활약 가장 많이 한 선수의 활약포인트를 입력시켜 경기 결과에 대한 데이터를 추가로 수집합니다. 이제 수집된 데이터를 바탕으로 경기의 승패를 판정해주고(토너먼트 특성상 무승부는 배제하여 판정합니다.) 경기의 중요도, 경기를 구경한 관중의 숫자, 팀의 명성 합, 승패 결과에 따라 경기를 통한 각 팀의 분배가 결정되는데, 경기에서 승리하고 관중의 숫자가 높을수록, 경기의 중요도가 높을수록, 경기하는 두 팀의 명성 합이 높을수록 분배되는 보상의 가치가 높습니다. 마지막으로 경기에서 각 팀에서 가장 많이 활약한 선수의 활약포인트를 비교하여 가장 높은 활약포인트를 기록한 선수에게 MVP선수라는 명예로운 타이틀이 부여될것입니다.(이 시스템은 사용자가 자유롭게 원하는 팀의 경기를 입력하고, 경기의 MVP선수, 승패 정보 등을 간편하게 확인하실 수 있습니다.)



## 3. 예상 기능 및 메뉴 (최소 5개)
1.경기중요도 입력(ex결승, 준결승, 8강, 예선 등)
2.각팀의 포지션 입력
3.각팀의 전술(ex압박축구, 패스축구, 수비적인 축구 등)
4.각팀의 주장선수 입력
5.관중숫자
6.각 팀의 최우수 선수의 활약포인트 입력
7.각팀의 골 숫자 입력
8.승패 판정(무승부는 없음)
9.경기중요도 및 승패와 관중 숫자에 따라 보상 배정
10.활약포인트를 고려한 MVP선수 선발
11.팀의 리스트
12.팀의 명성
